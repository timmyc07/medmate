# 資料來源、匯入與發布規則

查證日期：2026-10-14；藥品官方詳細資料的 production migration/import 需依維運流程另行執行。正式來源為政府發布的 CSV；不是從 Parallels SQL Server 直接 dump。Mac 端目前無法連到 VM 的 SQL Server listener，因此網站資料採已核對的 CSV 來源。原始 CSV 保持在 repo 外，匯入批次的 hash、列數與 batch ID 寫入資料庫 `source_imports`。

## 官方來源與驗證

本次支援的來源檔案均與官方直接下載資源逐位元組比對一致，正式匯入時亦重新從官方 URL 下載並核對 SHA-256。來源頁標示政府資料開放授權條款第 1 版；展示時保留資料來源和查詢日期。來源更新頻率依官方頁列示。

網站所有路由在共用頁尾顯示使用者提供的全民健康保險標誌，以及可點擊的政府資料來源清單。清單涵蓋藥局目錄、藥品許可證、健保藥品使用量/目錄、FDA 藥品外觀、行政區參考資料與政府資料開放授權條款。FDA 藥品外觀資料目前仍只有本機來源檔，官方資料集頁與授權細節待核實；頁尾僅連到 FDA 開放資料入口，不對未確認項目宣稱特定授權。

SHA-256 對應本機核對的官方檔案。36 與 43 來源是 ZIP 封裝，表內 hash 為解出的 CSV；53 是直接 CSV，表內 hash 為原始檔。FDA 藥局資料有兩組重複機構欄位，匯入器以名稱和地址組合鍵去重，故實際保存 9,153 列；藥品同一許可證號的重複列以許可證號去重，逐筆檢查重複項的公開欄位相同，保存 66,510 列。CSV 原始列數與 hash 均存入 `source_imports`。匯入器不讀入 FDA 藥局負責人欄位，也不建立對應資料庫欄位。

藥品官方詳細資料由 `scripts/import-medicine-information.mjs` 以單一交易匯入：`36_2.csv` 的用法用量更新 `medicines.usage_dosage`，`43_2.csv` 寫入一對多的 `medicine_ingredients`，`53_2.csv` 寫入公告與可精確配對的 `medicine_safety_license_links`。2026-10-14 已匯入隔離 branch 及 production：36 原始 72,074 列、43 原始 126,019 列（正規化後 125,669 筆）、53 共 129 筆，11 筆含許可證候選、13 筆建立精確關聯；production 批次 ID 為 `0b99c3c0-367a-45d6-aaa5-1e1191b714f1`。目前來源沒有完整的逐藥品副作用、禁忌或交互作用欄位；網站會明確顯示未提供，不以藥名、成分或相似文字推測。

53 資料是歷史公告集合；未列入公告不代表沒有風險。健保使用量排行的 `licId` 與 FDA 完整許可證字號尚無已核實的正式對照，因此排行頁不顯示推測的藥證、外觀或官方用藥資料；只有依完整許可證字號搜尋時才套用上述精確關聯。

## 更新與回復

### 藥品使用量排行（新增資料集）

排行來源為使用者提供的中央健康保險署 `A21030000I-E41005-001.csv` 至 `A21030000I-E41005-005.csv`；藥品名稱、成分及劑型來自 `A21030000I-E41001-001.csv`，外觀來自 FDA `42_2.csv`。匯入器會按年度與健保藥品代碼去重；榜單依最新資料年度「含包裹支付的醫令量合計」排序，每頁最多 50 項。資料期間由 CSV 的申報年月決定，115 年目前為 11501–11507，不能稱為全年。醫令量是彙總申報量，不代表病人數或實際服藥量。

健保清單網址的 `licId` 為 8 位數識別碼，FDA 外觀 CSV 的 key 是完整許可證字號，兩者沒有已核實的官方對照。FDA 許可證 CSV 的「通關簽審文件編號」尾碼與部分 `licId` 數字相似，但實際資料有一對多衝突；在取得並驗證正式識別碼關係前，不得將這種數字相似度當成藥品對照。介面目前只採完整許可證字號精確配對，其他項目顯示中性占位，不以品名或子字串推測。外觀圖只接受 `https://mcp.fda.gov.tw/` 網址。FDA 圖片來源目前是本機 `42_2.csv`，其精確官方資料集頁、更新頻率及授權欄位仍待核實；在核實前不得宣稱圖片涵蓋率或另行推定授權。

新增的 migration 為 `db/migrations/002_medicine_usage.sql`。先確認 `DATABASE_URL_UNPOOLED` 指向隔離測試 branch，再執行 `npm run db:migrate`；使用者資料夾保持 repo 外，執行 `npm run db:import-medicines -- "/Users/reikous/Downloads/藥品資料庫"`。匯入涵蓋民國 111–115 年藥品使用量檔，並在同一交易寫入目錄、外觀、期間、筆數與原始 CSV SHA-256。匯入器缺檔或資料驗證失敗時會 rollback。不要對 production 執行，除非已先完成測試 branch 匯入與筆數/排名驗證及另行安排發布。

執行 `npm run db:migrate` 套用 `db/migrations/001_catalog.sql`；執行匯入前，將三份官方下載 CSV 解壓/命名為 `35_2.csv`、`36_2.csv`、`A21030000I-D21005-001.csv` 放在同一個本機資料夾，再以 `DATABASE_URL_UNPOOLED=<direct Neon URL> npm run db:import -- <資料夾>` 執行。direct URL 只供人工觸發的 migration/import 使用，不設於 Render。匯入器以單一交易整批刪除並重建三張目錄表；既有藥局座標會按醫事機構代碼及地址未變條件暫存並在匯入後恢復，地址變更時不沿用舊座標。任何來源驗證或資料庫錯誤都會 rollback，批次 metadata 只在交易提交時更新。匯入前須確認三個來源檔齊全並完成來源 hash/schema 檢查；不要把 CSV 放進 repo、Render 檔案系統或瀏覽器。

2026-10-08 更新使用 `/Users/reikous/Downloads/藥品資料庫` 中的 `35_2.csv`、`36_2.csv`、`A21030000I-D21005-001.csv` 完成匯入。該目錄的 `37_2.csv`、`42_2.csv`、`A21030000I-E41001-001.csv` 及健保藥品 B5/TXT 檔屬於其他資料集，尚未對應目前的資料庫 schema/API；新增前須各自查核官方欄位、使用條款與識別碼，設計獨立資料表及搜尋介面，不能混入藥品許可證資料表。

## 使用限制

藥品頁目前以 TFDA 許可證與外觀資料提供症狀／用途及圖片。健保藥品目錄與使用量資料目前沒有已核實的藥證價格對照，因此卡片不填入推測金額；價格欄位僅保留給未來接上正式健保支付標準來源。搜尋症狀時只比對 TFDA 適應症與可追溯的 `medicine_symptoms` 詞彙，不代表診斷或保證療效。

- 地址轉座標使用 Google Geocoding API 的即時結果，僅供使用者當次指定區域地圖呈現，不寫入資料庫或快取。依 [Google Geocoding API 政策](https://developers.google.com/maps/documentation/geocoding/policies)，未取得另行協議前不可儲存 Place ID 以外的地理編碼結果；地圖內容須使用 Google Map 並提供其標誌及歸屬資訊。

- 查詢是一般公開資訊，不提供診斷或治療建議；用藥疑問請諮詢藥師或醫療人員。
- 目前搜尋使用健保特約藥局來源；FDA 藥局 registry 獨立保留，不做模糊比對合併。
- 網站呈現資料擷取批次日期，官方資料集更動後應重新下載、比對 schema/hash、匯入並驗證筆數。
- 藥局來源提供地址文字；缺少座標時可由維運人員使用 TGOS 批次門牌地址比對 CSV 離線補齊。匯出/回匯流程見[維運文件](operations.md#tgos-批次補齊藥局座標)。僅在機構代碼、原始地址及 WGS84 座標驗證通過後，才將座標寫入藥局資料表；附近藥局即時排序使用此已匯入座標。TGOS 批次服務每日上限為 10,000 筆且非同步，不能用於線上即時地址定位。若地圖地址仍缺座標，現有 Google Geocoding 結果只供當次地圖顯示，不寫入資料庫或快取。
- 藥局查詢的縣市/行政區選單採全台 22 縣市、368 鄉鎮市區，依內政部戶政司 114 年開放資料交叉核對。此行政區清單只供篩選使用，不代表藥局地址已完成座標轉換。
- 開放授權來源：[政府資料開放授權條款第 1 版](https://data.gov.tw/license)。
