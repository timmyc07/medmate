## 目前狀態

網站尚未載入或公開任何附件 CSV、SQL Server 資料列或資料庫匯出。目前 API 會回覆通用服務無法使用訊息，介面也標示線上資料尚未啟用。2026-10-08 已將三份附件分別與官方直接下載資源比對，內容 SHA-256 完全相同；官方頁列出的政府資料開放授權條款第 1 版允許再利用，仍須保留來源/授權標示。藥局/藥品狀態的業務篩選規則與線上資料更新管線仍待完成。

已由本機附件的標題列確認欄位：

- `35_2.csv` 含藥局機構狀態、名稱、地址、電話及健保特約欄位，也含負責人姓名與性別。若日後取得發布資格，姓名與性別必須排除。
- `36_2.csv` 含藥品許可證號、註銷狀態/日期/理由、有效日期、中文品名及適應症。資料沒有副作用欄位。
- `A21030000I-D21005-001.csv` 含醫事機構資料、合約類別、終止合約或歇業日期、地址、電話及固定看診時段。

上述欄位說明依官方資源及附件標題列核對。2026-10-08 重新下載官方現行資源並比對解壓後/原始 CSV 位元組：三份附件都與官方下載完全一致。這只證明查證當日版本一致；正式更新流程仍須從官方 URL 重新抓取，不應把 CSV 提交至 GitHub。各狀態欄位的有效性語意仍須依資料集說明落實，不能以單一欄位猜測。

## 發布前必要查證

1. 匯入時優先重新下載上述官方資源而非沿用附件；記錄正式資料集頁、下載/API URL、授權條款、更新頻率、最後更新日，並比較附件 schema/內容版本。
2. 依官方欄位文件定義藥局有效狀態與終止/歇業日期規則，以及藥品註銷與有效日期規則。不能只因附件存在某個欄位就自行推定該欄位的有效值。
3. 記錄來源 URL、下載日期、批次識別、原始狀態與有效日期；建立可重複匯入、重複識別碼處理、異常隔離、筆數核對與回復程序。
4. 只有明確確認發布資格後，才安排受限權限的託管資料庫。不可將 Parallels VM 的 SQL Server 對外開放。
